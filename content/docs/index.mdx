Zoteus is an open-source [MCP (Model Context Protocol)](https://modelcontextprotocol.io) server for [Zotero](https://www.zotero.org). It exposes your Zotero library to Claude, Claude Code, Cursor and any other MCP client as a set of typed, safe tools: search by keyword or by meaning, quote passages from your PDFs with page locators, format citations in any CSL style, add items by DOI, write back to your library, and explore the wider literature around any paper.

## Quick start

Add Zoteus to Claude Code in one step:

```bash
claude mcp add --transport stdio zoteus -- npx -y @oscardvs/zoteus
```

Or run it directly:

```bash
npx -y @oscardvs/zoteus
```

With the Zotero desktop app running and **Settings, Advanced, "Allow other applications on this computer to communicate with Zotero"** ticked, reads and personal-library writes need no API key. Add a key from [zotero.org/settings/keys](https://www.zotero.org/settings/keys) for sync, group libraries, and writes when the app is closed:

```bash
claude mcp add --transport stdio zoteus -e ZOTERO_API_KEY=your_key -- npx -y @oscardvs/zoteus
```

Claude Desktop users can skip the terminal entirely: download `zoteus.mcpb` from the [latest release](https://github.com/oscardvs/zoteus/releases/latest) and double-click it. See [Connect Claude to Zotero](/docs/connect-claude-to-zotero).
