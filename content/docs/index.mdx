Zoteus is an open-source [MCP (Model Context Protocol)](https://modelcontextprotocol.io) server for [Zotero](https://www.zotero.org). It exposes your Zotero library to AI assistants as a suite of typed, safe tools — search by meaning, format citations in any style, write back to your library, ground answers in PDF text, and explore the wider literature around any paper.

## Get started

Install and add to Claude Code in one step:

```bash
claude mcp add zoteus -e ZOTERO_API_KEY=your_key -- npx -y @oscardvs/zoteus
```

Or run it directly:

```bash
ZOTERO_API_KEY=your_key npx -y @oscardvs/zoteus
```

Get a Zotero API key at [zotero.org/settings/keys](https://www.zotero.org/settings/keys). For local-only reads from the Zotero desktop app no key is required — see [Configuration](/docs/configuration).
